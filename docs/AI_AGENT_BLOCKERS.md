# AI Agent Blockers / Human Follow-up

A blocker logged here MUST NOT stop unrelated work.

## Operating rule
If a specific task requires a human-only external action (for example login, MFA, CAPTCHA, unavailable credential, or external authorization), the agent must document it and continue with every independent task that can proceed.
